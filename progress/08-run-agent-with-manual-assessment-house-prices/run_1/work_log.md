## Iteration 3
- **Timestamp**: 2026.05.17 19:00:00
- **Train Log MSE**: 9.46e-03
- **Test Log MSE**: 1.65e-02
- **Intended change**: Add LightGBM as a third diverse base learner, replace fixed-weight blending with stacking (Ridge meta-learner on OOF predictions), add richer interaction features
- **Reasoning**: Iteration 2 achieved test Log MSE 1.65e-02 with a 25 XGBoost + 5 Lasso ensemble blended at fixed 60/40 weights. Three key improvements: (1) **LightGBM diversification**: LightGBM uses leaf-wise growth and histogram-based splitting, which captures different patterns than XGBoost's depth-wise approach. Adding 5 seeds × 5 folds = 25 LGBM models creates a three-model ensemble (XGB+LGB+Lasso) that reduces variance through model diversity — the single biggest driver of stacking gains. (2) **Stacking meta-learner**: The fixed 60/40 blend is suboptimal because it cannot adapt blend weights to different input regions. A Ridge regression meta-learner trained on out-of-fold predictions learns optimal stacking coefficients automatically. This is particularly valuable because XGB and LGB have complementary strengths (XGB is more conservative/stable, LGB captures finer patterns) and the meta-learner can assign different weights than a manual grid search. (3) **Richer features**: Added Neighborhood_Qual interaction (neighborhood quality is the strongest price driver), SeasonSold (housing market seasonality from MoSold), OverallQual_cubed and GrLivArea_sq/TotalSF_sq (polynomial features for the dominant predictors), BsmtRatio/GarageRatio/PorchRatio (proportional features capturing composition of living space). These features particularly help the linear Lasso model.

## Iteration 4
- **Timestamp**: 2026.05.17 20:00:00
- **Train Log MSE**: 8.95e-03
- **Test Log MSE**: 1.58e-02
- **Intended change**: Add smoothed target encoding for high-cardinality categoricals, replace Lasso with ElasticNet, fix LotFrontage imputation with neighborhood median, remove duplicate interaction feature
- **Reasoning**: Iteration 3 achieved test Log MSE 1.65e-02. The stacking ensemble (XGB+LGB+Lasso with Ridge meta-learner) has limited feature representation for categoricals — LabelEncoder assigns arbitrary integer orderings that don't reflect price signals. Four improvements: (1) **Smoothed target encoding**: For 12 high-cardinality categoricals (Neighborhood, MSSubClass, Exterior1st/2nd, Condition1/2, SaleType, SaleCondition, HouseStyle, BldgType, RoofMatl, Functional), replace naive label encoding with smoothed mean-encoded features. Each category value is mapped to the average log(SalePrice) of that group, regularized with smoothing factor=10 toward the global mean to prevent overfitting on rare categories. This directly injects the most predictive signal (average price per category) as a numeric feature, which is especially valuable for the linear model. The TE features are computed before label encoding so the original string values are available. (2) **ElasticNet replacing Lasso**: Lasso (pure L1) tends to arbitrarily select one feature from a group of correlated features and zero-out the rest, which loses information when TE features correlate with original features. ElasticNet (L1+L2, l1_ratio=0.7) preserves correlated feature groups better while still performing feature selection — it should retain both the original and TE versions of Neighborhood etc. (3) **LotFrontage neighborhood-median imputation**: Previously filled with 0, but LotFrontage missingness is structural (no frontage on street) and varies by neighborhood. Using neighborhood-level median imputation is the standard approach for this dataset and produces more realistic feature values. (4) **Remove duplicate feature**: OverallQual_OverallCond was identical to OverallCond_Qual — removed the duplicate to avoid redundant features. Additionally added NeighborhoodQual_te and MSSubClassQual_te interaction features (TE × OverallQual) which combine the strongest categorical signal with the strongest numeric predictor.
- **Code diff**: Added TE_COLS list (12 categoricals), TE_SMOOTH constant, _te_maps/_te_global_mean to Model.__init__. Target encoding logic added to _preprocess (before label encoding) — computes smoothed mean per category on training data, maps on inference. Replaced Lasso import with ElasticNet, _lasso_models with _enet_models, Pipeline uses ElasticNet(alpha=0.001, l1_ratio=0.7). LotFrontage now imputed by neighborhood median before falling back to 0. Removed OverallQual_OverallCond (duplicate of OverallCond_Qual). Added NeighborhoodQual_te and MSSubClassQual_te interaction features. Save/load updated to persist te_maps and te_global_mean.

## Iteration 5
- **Timestamp**: 2026.05.17 21:00:00
- **Train Log MSE**: 8.60e-03
- **Test Log MSE**: 1.57e-02
- **Intended change**: Fix target encoding data leakage with K-Fold CV encoding, add interaction features, tune ElasticNet, extend log1p transforms
- **Reasoning**: Iteration 4 achieved test Log MSE 1.58e-02 but has a critical data leakage bug: target encoding is computed on the full training set, then the same data is used in K-Fold CV where validation folds see TE values computed using their own targets. This inflates the OOF predictions from base models (especially ElasticNet which heavily relies on TE features), making the stacking meta-learner learn suboptimal coefficients. The fix: use K-Fold cross-validated target encoding during training — for each fold, compute TE statistics only from the training portion and apply to the validation portion. This eliminates leakage and produces honest TE features that reflect what the model will see at inference time (where TE is computed from the full training set). The full-training-set TE maps are still stored for inference. Additionally: (1) Added HouseStyleQual_te interaction (HouseStyle is a strong price differentiator for story height), Ext1Ext2_te_avg (averages the two exterior TE signals which are highly correlated), OverallQual_HouseAge (quality depreciated by age), GrLivArea_LotArea, TotalBath_Qual interactions. (2) Extended SKEWED_COLS with EnclosedPorch, ScreenPorch, TotalPorchSF to capture skewness in porch features. (3) Tuned ElasticNet from alpha=0.001/l1_ratio=0.7 to alpha=0.0005/l1_ratio=0.5 — with more features and honest TE, less L1 regularization and lower alpha allows the linear model to better leverage the richer feature set without over-constraining.
- **Code diff**: Replaced full-training-set TE computation with K-Fold CV target encoding (5-fold, random_state=2024) in the is_train branch of _preprocess. Added HouseStyleQual_te, Ext1Ext2_te_avg, OverallQual_HouseAge, GrLivArea_LotArea, TotalBath_Qual interaction features. Extended SKEWED_COLS with EnclosedPorch, ScreenPorch, TotalPorchSF. ## Iteration 6
- **Timestamp**: 2026.05.17 22:30:00
- **Train Log MSE**: 8.72e-03
- **Test Log MSE**: 1.54e-02
- **Intended change**: Add sklearn GradientBoostingRegressor as 4th base model for diversity, replace Ridge meta-learner with NNLS (non-negative least squares) stacking, decouple KFold seeds between XGB and LGB, extend target encoding to 7 more categoricals, add new interaction features
- **Reasoning**: Iteration 5 achieved test Log MSE 1.57e-02 with a 3-model stacking ensemble (XGB+LGB+ElasticNet with Ridge meta-learner). Five improvements target different sources of gain: (1) **sklearn GradientBoostingRegressor as 4th base model**: sklearn's GBR uses Friedman's gradient boosting with MSE-based split finding, which differs from XGBoost's regularized objective and LightGBM's histogram-based approach. This provides genuine model diversity for the stacking ensemble. Configured with n_estimators=2000, learning_rate=0.01, max_depth=4, min_samples_leaf=10, subsample=0.7, max_features=0.6, and n_iter_no_change=50 for early stopping. 3 seeds × 5 folds = 15 GBR models. (2) **NNLS meta-learner replacing Ridge**: Ridge regression can assign negative weights to base models, which is undesirable in stacking — a negative weight means "predict opposite of this model," which is unstable and overfits to OOF idiosyncrasies. NNLS (non-negative least squares from scipy.optimize.nnls) constrains all stacking weights to be non-negative, which is theoretically motivated (all base models predict in the same direction) and empirically more robust. Added a fallback: if Ridge (alpha=10) yields lower OOF MSE than NNLS, use Ridge instead. The meta-learner now stores explicit weights and intercept rather than a fitted model object. (3) **Decoupled KFold seeds**: Previously both XGB and LGB used random_state=42+seed, meaning they saw identical fold splits — this means the OOF predictions have correlated errors, reducing stacking diversity. Changed LGB to random_state=77+seed and GBR to random_state=123+seed, decorrelating the fold structures between model types. (4) **Extended target encoding**: Added MSZoning (zoning classification strongly affects land value), Foundation (foundation type affects structural quality perception), GarageType, LotConfig, RoofStyle, Heating, Electrical — 7 additional categoricals with meaningful price variation. Total TE_COLS now 19 features. Also added TE×Quality interaction features for MSZoning, Foundation, and GarageType, plus Neighborhood_te×TotalSF (location×size is the strongest interaction in real estate). (5) **New features**: OverallQual×GarageArea, OverallQual×TotalBath, OverallQual²×GrLivArea (3-way interaction), RemodAge×OverallQual (quality depreciation), KitchenQual×OverallQual, ExterQual×OverallQual, TotalSF_log1p, GrLivArea_log1p, HasLowQualFin, HasPoolOrDeck, YrSinceRemod, OverallQual×BsmtQual.
- **Code diff**: Added GradientBoostingRegressor import, scipy.optimize.nnls import. Added _gbr_models list, N_SEEDS_GBR=3 constant. Extended TE_COLS from 12 to 19 categoricals. Changed LGB KFold random_state from 42+seed to 77+seed. Added GBR training loop with early stopping (n_iter_no_change=50). Replaced Ridge meta-learner with NNLS meta-learner (with Ridge fallback). - **Reasoning**: Iteration 6 achieved test Log MSE 1.54e-02 with a 4-model stacking ensemble (XGB+LGB+GBR+ElasticNet with NNLS/Ridge meta-learner). Three improvements target different sources of gain: (1) **CatBoost as 5th base model**: CatBoost provides the most algorithmically distinct boosting implementation in the ensemble. Unlike XGBoost (regularized depth-wise), LightGBM (histogram leaf-wise), and sklearn GBR (Friedman's MSE boosting), CatBoost uses ordered boosting (prevents prediction shift from target leakage) and ordered target encoding of categorical features. CatBoost's native categorical handling with `cat_features` indices directly processes label-encoded columns using its own internal target statistics, which captures different patterns than the other tree models that treat label-encoded values as ordinal. This is the single most impactful change — stacking gains are driven by error diversity among base models, and CatBoost's unique inductive bias (symmetric trees, ordered boosting) maximally decorrelates its residuals from XGB/LGB/GBR. Configured with iterations=5000, learning_rate=0.01, depth=4, l2_leaf_reg=3.0, subsample=0.7, colsample_bylevel=0.6, early_stopping_rounds=100. 3 seeds × 5 folds = 15 CatBoost models with decoupled KFold seed (random_state=200+seed). These features capture relative positioning within a neighborhood — a high-quality house in a low-quality neighborhood may be priced differently than the same quality house in a high-quality neighborhood. These are particularly helpful for the linear ElasticNet model. (3) **Additional TE×Qual interactions**: Added SaleConditionQual_te and Condition1Qual_te — SaleCondition captures whether the sale type (normal, partial, family, etc.) affects price differently at different quality levels, and Condition1 (proximity to roads/railroads) interacts with quality. These features extend the existing pattern of TE×Qual interactions that have been incrementally valuable in previous iterations.

## Iteration 8
- **Timestamp**: 2026.05.18 15:00:00
- **Train Log MSE**: 7.86e-03
- **Test Log MSE**: 1.56e-02
- **Intended change**: Replace NNLS meta-learner with enhanced Ridge meta-learner on expanded features (pairwise prediction products + summary statistics), switch ElasticNet folds to StratifiedKFold, increase CatBoost regularization
- **Reasoning**: Iteration 7 achieved test Log MSE 1.54e-02 with a 5-model stacking ensemble using NNLS/Ridge meta-learner on 5 raw base predictions. Three improvements target different sources of gain: (1) **Enhanced meta-learner with pairwise interactions**: NNLS on 5 raw predictions is overly restrictive — it can only learn linear blend weights. The 5 base models (XGB, LGB, GBR, Cat, ENet) have complementary strengths: tree ensembles capture non-linear patterns while ElasticNet captures linear effects. By expanding the meta-features from 5 to 20 (5 base predictions + 10 pairwise products + mean + std + max + min + range), the Ridge meta-learner can learn when specific model combinations are more/less reliable. For instance, XGB×LGB captures whether both tree models agree (high agreement = higher confidence), while XGB×ENet captures tree-linear synergy. The pairwise terms act as confidence-weighted blending, allowing the meta-learner to upweight predictions when models agree and downweight when they disagree. Ridge with alpha=1.0 provides sufficient regularization to prevent overfitting on these expanded features. This replaces the NNLS/Ridge selection logic with a single, more expressive meta-learner. (2) **StratifiedKFold for ElasticNet**: ElasticNet is the most sensitive model to fold composition because it relies heavily on target-encoded features that can vary significantly across folds. Regular KFold may create imbalanced folds where some price ranges are over/under-represented, leading to unstable OOF predictions. StratifiedKFold on 10 quantile bins of SalePrice ensures each fold has a representative price distribution, producing more stable and accurate OOF ENet predictions. (3) **CatBoost regularization increase**: Changed l2_leaf_reg from 3.0 to 5.0 to reduce CatBoost's tendency to overfit on the small dataset (~1450 samples after outlier removal), which also improves the quality of its OOF predictions for the meta-learner.
- **Code diff**: Removed scipy.optimize.nnls import. Added META_ALPHA=1.0 constant. Added _build_meta_features static method that constructs 20 meta-features (5 base + 10 pairwise + 5 stats). Replaced NNLS/Ridge dual meta-learner with single Ridge(alpha=1.0) trained on expanded meta-features. Switched ElasticNet KFold to StratifiedKFold with 10 quantile bins. Changed CatBoost l2_leaf_reg from 3.0 to 5.0. Removed _use_nnls, _meta_weights, _meta_intercept from __init__ and save/load. ## Iteration 9
- **Timestamp**: 2026.05.18 20:00:00
- **Train Log MSE**: 8.41e-03
- **Test Log MSE**: 1.54e-02
- **Intended change**: Add KernelRidge (polynomial) as 6th base model, replace Ridge meta-learner with RidgeCV, simplify meta-features by removing pairwise prediction products
- **Reasoning**: Iteration 8 regressed from 1.54e-02 to 1.56e-02 test Log MSE. The most likely cause was the pairwise prediction products in the meta-features (10 additional features from 5 base models), which amplify noise in the meta-learner on ~1450 training samples. Three changes address this: (1) **Remove pairwise products from meta-features**: The 10 pairwise terms (e.g., XGB×LGB, XGB×GBR) doubled the meta-feature dimension from 10 to 20 with highly collinear inputs. Since base model predictions are already correlated (all predict log(SalePrice) in the ~11.5–12.5 range), their products carry little independent information but introduce noise from prediction errors multiplied together. Reverting to just raw predictions + summary statistics (mean, std, max, min, range, median = 12 features for 6 base models) is more robust. Added median as an additional robust central tendency statistic. (2) **KernelRidge as 6th base model**: KernelRidge with polynomial kernel (degree=2, coef0=2.5) provides a fundamentally different inductive bias from all existing models — it captures smooth non-linear relationships via kernel methods rather than tree-based piecewise partitioning or linear regularization. Wrapped in RobustScaler pipeline to handle feature scale differences. This is one of the strongest individual models on Ames Housing in the Kaggle literature. 3 seeds × 5 folds = 15 KRR models with decoupled KFold seed (random_state=300+seed). (3) **RidgeCV meta-learner**: Replaced Ridge with fixed alpha=1.0 with RidgeCV searching over 50 alphas on a log scale (1e-3 to 1e3). The fixed alpha=1.0 was suboptimal — with 6 base models and 12 meta-features, the optimal regularization strength depends on the correlation structure of the OOF predictions, which changes with each new base model. RidgeCV automatically selects the best alpha via leave-one-out cross-validation (Ridge's LOO-CV is O(n) via the SVD trick, making it very fast). This removes a hyperparameter that was previously hand-tuned and may have been too low (causing the meta-learner to overfit to OOF idiosyncrasies).
